## Nossas respostas

### 1. O diff
A cor vermelha representa o conteúdo removido ou substituído, enquanto a cor verde representa o conteúdo adicionado ao projeto.

### 2. O conflito
Um conflito acontece quando duas pessoas modificam a mesma parte de um arquivo de maneiras diferentes. Os três marcadores indicam o início da alteração de uma branch (`<<<<<<<`), a separação entre as duas versões (`=======`) e o final da outra alteração (`>>>>>>>`). Nosso texto final ficou: "Dia de estudo: terça e quinta-feira".

### 3. A revisão
Recebemos comentários sugerindo melhorias nas explicações de Git, Commit, Pull Request e nos passos do GitHub Flow. O Request changes é usado para solicitar alterações antes da aprovação. O Approve significa que o revisor aprovou as mudanças e considera o trabalho pronto para ser integrado.

### 4. Segurança
Não. Mesmo que a informação seja apagada no commit seguinte, ela pode continuar aparecendo no histórico do Git. Dois exemplos de informações que nunca devem ser publicadas são senhas e números de documentos pessoais.
