1. Git: Sistema que registra as alterações feitas em um projeto e permite acompanhar seu histórico.

2. GitHub: Plataforma online onde podemos armazenar projetos e trabalhar em equipe.

3. Repositório: Local onde ficam guardados os arquivos e o histórico de um projeto.

4. Commit: Registro de uma alteração feita no projeto.

5. Branch: Ramificação que permite desenvolver ou testar mudanças sem alterar diretamente o código principal.

6. Main: Branch principal do projeto, onde fica a versão considerada principal.

7. Merge: Ação de juntar as alterações de uma branch com outra.

8. Pull Request: Pedido para que as alterações feitas em uma branch sejam analisadas e adicionadas a outra.
